# 🦇 Rookie Origins

> *Every legend has a first night out.*

This is where I started. Not the polished work, that lives on my profile, but the first notebooks, the first models that actually ran, and the first time an accuracy score came back and I thought, "wait, it works?"

Some of these are messy. A few make me wince. All of them taught me something, and I kept them here instead of hiding them.

## What's inside

Regression, classification, NLP, computer vision, recommender systems, and a bit of math theory. Mostly classic datasets, because that's how you learn the craft before you try to build something new.
